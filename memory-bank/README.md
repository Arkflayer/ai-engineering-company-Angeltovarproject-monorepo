# Memoria del proyecto TrackFlow

Este directorio es la fuente persistente de contexto empresarial, técnico y de progreso del repositorio. Al inicio de cada sesión, lee estos tres archivos:

- [`projectbrief.md`](./projectbrief.md) — negocio, objetivos del proyecto y problema que resuelve.
- [`techContext.md`](./techContext.md) — stack, decisiones de arquitectura y restricciones técnicas.
- [`progress.md`](./progress.md) — estado actual y próximos pasos previstos.

Mantén estos documentos alineados con `CONTEXT.md` y `CONTEXT.es.md` cuando cambien hechos duraderos o la arquitectura del proyecto. Separa los hechos confirmados de las suposiciones; no inventes datos operativos ni des a entender que existen integraciones que aún no se han implementado.
