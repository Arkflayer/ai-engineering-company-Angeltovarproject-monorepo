# Memoria del proyecto TrackFlow

Este directorio es la fuente persistente de contexto empresarial y técnico del repositorio. Lee estos documentos antes de planificar o modificar una funcionalidad:

- [`contexto-empresarial.md`](./contexto-empresarial.md) — empresa, modelo operativo, departamentos, restricciones y prioridades.
- [`contexto-tecnico.md`](./contexto-tecnico.md) — arquitectura del repositorio, ubicación del código, convenciones de implementación y limitaciones conocidas.

Mantén estos documentos alineados con `CONTEXT.md` y `CONTEXT.es.md` cuando cambien hechos duraderos o la arquitectura del proyecto. Separa los hechos confirmados de las suposiciones; no inventes datos operativos ni des a entender que existen integraciones que aún no se han implementado.
